# Colony Map Viewer

円柱状のスペースコロニー（O'Neill シリンダー）の内面に地図を巻き付けてレンダリングする、
自車をうしろから見る TPS 視点のカーナビ POC。

遠方の道路や目的地が地平線の下に沈まず「前方の空にせり上がって」見えるため、
**遠距離の目的地と近距離の自車周辺を 1 画面に同時に**収められる。

公開: https://aigamoid.github.io/ColonyMapViewer/

## コンセプト

平坦なローカル地図ジオメトリ（x=東, z=北, y=標高）を、半径 R の円柱内面へ
頂点シェーダで巻き付ける（[`src/colony.ts`](src/colony.ts)）。
自車は円柱内面の最下部に立ち、`forward` 方向へ地面がせり上がる。

```
s      = forward 方向への距離
θ      = θmax · s / (s + R·θmax)        巻き上げ角（上限つき）
radial = R - h                          高さは円柱軸へ向かう
view   = forward·(radial·sinθ) + axis·t + up·(R - radial·cosθ)
```

既定は R=1800m、θmax=80°。前方 20km までが画面内に収まる。

### 実装上の要点

素直に θ = s/R とすると破綻する。実際に踏んだ落とし穴と対処:

- **遠方が背後へ回り込む**: θ が 2π を超えると遠景が頭上を越えて裏へ消える。
  θ に上限を設け、近距離は円柱と一致させつつ遠方を画面上端に積み上げる。
- **飽和のさせ方が肝**: tanh は指数的に飽和するため 5km と 20km の角度差が
  0.05°（1px 未満）しかなく、遠景がすべて 1 本の線に潰れる。
  有理関数 `θmax·s/(s+a)` なら同条件で 9.4° 開き、20km 先まで判別できる。
- **θ > 90° で遠景が「屋根の壁」に潰れる**: 建物の「上」が観測者を向くため。
  θmax はその手前（既定 80°）に抑える。
- **高い建物が観測者を串刺しにする**: 高さ = 円柱軸方向なので、R より高い建物は
  中心を突き抜ける。R は最大建物高さの数倍を取り、radial を軸手前でクランプする。
- **遠方の高層ビルが道路を隠す**: 近距離は実寸、遠距離は高さを圧縮する
  （`aBaseY` 属性 + 頂点シェーダ）。カーナビの模式的な 3D 建物と同じ考え方。
- **地形より下に敷いた平面は巨大なドームに化ける**: 「低い」＝「軸から遠い」ため。
  地面は terrain メッシュだけが担当する。
- **地図タップの当たり判定**: 変形は頂点シェーダ側なので、three のレイキャストは
  「変形前」のジオメトリに当たってしまう。ビュー空間で「地面 = 円柱内面」と
  解析的に交差させ、標高ぶんを反復で収束させる。

## 機能

- **3 表示モード**: ノースアップ / 目的地アップ / 自分（進行方向）アップ。
  目的地アップは進行方向を基準に最大 ±58° まで寄せる方式
  （真に目的地を向くと走行中の道が視界から外れるため）。
- **ナビ**: 地名検索・ルート探索・ターンバイターン案内・3D ルート表示。
- **現在地 HUD**: 東京都 › 千代田区 › 丸の内一丁目（逆ジオコーディング）と速度計。
- **ラベル**: 自治体 / 区 / 町名 / 道路名 / 施設 の 5 階層を色分け。
  遠いものは薄く大きく、近いものは濃く小さく。重なりは自動で間引く。
- **自車**: 実 GPS 追従 / フリードライブ（WASD）/ ルート自動走行。
  GPS が読み込み範囲外を返したら世界ごと現在地へ再アンカーする。
- **調整パネル**（左下）: コロニー半径・曲げの強さ・建物高さ・走行速度・
  カメラ距離・ラベル表示。

## データ

いずれも API キー不要。

| 用途 | ソース |
|---|---|
| ベクタータイル（建物・道路・水域・地名） | [OpenFreeMap](https://openfreemap.org/)（OpenMapTiles スキーマ） |
| 地形標高 | [AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/)（Terrarium PNG） |
| 地名検索・逆ジオコーディング | OSM Nominatim |
| ルート探索 | OSRM |

> Nominatim / OSRM はデモサーバ。利用規約上、本番運用は不可。自前ホストへ差し替えること。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ を生成
bash e2e/run.sh  # ヘッドレス Chrome + CDP による通し検証（15項目）
```

`main` に push すると [GitHub Actions](.github/workflows/deploy.yml) が
自動でビルドして GitHub Pages にデプロイする。

## クロスプラットフォーム

Web（PWA）として Android / iOS / Windows のブラウザでそのまま動作。
将来のネイティブ化は Capacitor でラップ可能（WebGL レンダラはそのまま）。
